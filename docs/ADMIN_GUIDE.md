# ADMIN_GUIDE.md — управление магазином

Вход: **/admin/login** (учётка суперадмина из seed: `admin@sb.eu / admin12345`).

## Разделы

| Раздел | Что делает |
| --- | --- |
| Dashboard | выручка/прибыль/продажи, топ товаров, баланс поставщиков, ошибки, кандидаты |
| Товары | каталог: себестоимость, цена клиента, прибыль, продажи; публикация/снятие |
| Категории | категории + наценка по категории |
| Кандидаты | найденные, но не опубликованные товары поставщиков |
| Поставщики | подключение API, синхронизация, blacklist |
| Связки товаров | canonical ↔ supplier products (приоритет, fallback) |
| Цены и наценки | наценка/мин.цена/мин.прибыль/ручная цена по каждому товару |
| Условия и гарантии | оригинал поставщика ↔ наш текст, diff, история, автообновление |
| Заказы / Платежи / Клиенты | операционные списки |
| Прибыль и аналитика | итоги по продажам |
| История цен / Логи синхронизации / Ошибки API / Audit logs | журналы |
| Настройки | глобальная наценка, округление, курс USDT→UZS |
| Администраторы | учётки и роли (RBAC) |

## Как добавить товар на сайт

1. **/admin/suppliers** → «Синхронизировать» (или дождитесь очереди).
2. **/admin/candidates** — для каждого кандидата видны себестоимость,
   рекомендуемая цена/наценка, прогноз прибыли, число похожих у поставщиков,
   Premium Emoji code.
3. Нажмите **«Добавить в продажу»** (создаёт товар и сразу публикует) или
   **«Создать черновик»** (товар в статусе DRAFT, публикация — на /admin/products).
4. Система **никогда не публикует автоматически** — только после действия админа.

## Цены и наценки

`/admin/pricing`. Порядок расчёта финальной цены:

1. `manualPrice` (ручная цена) — если задана, побеждает всё.
2. иначе `fixedPrice` — если включена фиксированная цена.
3. иначе `supplierPrice × (1 + markup%/100)`; markup берётся в порядке:
   товар → категория → глобальная наценка.
4. ограничение `minPrice`/`maxPrice`.
5. «красивое» округление (0.63→0.65, 8570→9000 и т.д.).
6. если прибыль < `minProfit` **или** цена ниже себестоимости — продажа
   **блокируется** (товар не продаётся с убытком).

Глобальная наценка, правило округления и курс USDT→UZS — в **/admin/settings**.
Каждое изменение цены пишется в `PriceHistory` (/admin/price-history).

## Условия и гарантии товара

`/admin/content/[id]` — экран с блоками для каждого поля (Описание, Условия,
Гарантия, Инструкция, Условия выдачи):

- **Оригинал поставщика** и **Текущий текст на сайте** рядом.
- **Diff** (что изменилось).
- **История изменений** (версии `ProductContentVersion`).
- Кнопка **«Принять новые условия поставщика»**.
- Кнопка **«Вернуть текст поставщика»** (одной кнопкой).
- **«Редактировать наш текст»** (после ручного редактирования режим станет MANUAL).
- Переключатель режима синхронизации на каждое поле:
  - `AUTO` — всегда брать текст поставщика (обновляется автоматически);
  - `MANUAL` — использовать наш текст, игнорировать поставщика;
  - `SUPPLIER_PLUS_OURS` — текст поставщика + наш дополнительный блок.

Весь HTML/Markdown от поставщика санитизируется (script/iframe/onerror
запрещены). При покупке сохраняется **снапшот** условий/гарантии/цены — старые
заказы не меняются, даже если поставщик потом изменит условия.

## Premium Emoji / логотип

Задаётся при одобрении кандидата и хранится в `PremiumEmojiConfig` (поле
`premiumEmojiCode` — **строка**, длинные коды без потери точности). Режимы:
`PREMIUM_EMOJI / LOGO / BOTH / NONE`. Компонент `<ProductTitleIcon>` рисует эмодзи
через провайдер, при недоступности — логотип, затем аккуратную текстовую иконку;
сломанное изображение не показывается никогда. Подключение реального источника
эмодзи — `registerEmojiProvider(...)` в `src/lib/emoji/renderer.ts`.

## Выбор поставщика и fallback

Движок (`src/lib/domain/supplier-selection.ts`) выбирает выгодного, но надёжного
поставщика (цена + наличие + статус API + успешность + скорость + рейтинг +
ручной приоритет; blacklist исключается). Ненадёжного не выберет только из-за
цены. При недоступности основного используется fallback — но если у fallback
хуже гарантия/условия, чем обещано клиенту, заказ уходит в `MANUAL_REVIEW`.
