# SoMaDeth «Buyer API» — авто-докупка товара

Поставщик-кошелёк: бот при покупке клиентом сам докупает товар и сразу выдаёт.
Три метода (авторизация `Authorization: Bearer <ключ>`):

- `GET  /api/telegram-buyer/balance`  — баланс кошелька
- `GET  /api/telegram-buyer/products` — список товаров
- `POST /api/telegram-buyer/purchase` — купить `{ product_id, qty }`

## 1. Переменные в Railway → Variables

**Ключ храните ТОЛЬКО здесь, не в коде и не в чате.**

| Переменная | Значение |
|---|---|
| `SOMADETH_API_URL` | origin без пути, напр. `http://15.235.133.206:55033` |
| `SOMADETH_API_KEY` | ключ `sk_live_…` из Telegram-бота поставщика |

Код читает имя переменной терпимо к регистру — подойдёт и `SoMaDeth_API_URL` /
`SoMaDeth_API_KEY`, и `BUYER_API_URL` / `BUYER_API_KEY`. Но **ключ обязателен** —
без `..._API_KEY` источник не включится.

`SUPPLIER_MODE` для этого поставщика не нужен (он относится к другой,
mock/live-системе Next.js). Можно оставить как есть.

## 2. Привязать товар к поставщику (админка)

1. Открой **Админка → Импорт из API**.
2. В переключателе источников появится **SoMaDeth**.
3. Увидишь баланс кошелька и список товаров поставщика.
4. У нужного товара задай наценку % и нажми **«На продажу»** — бот создаст товар,
   привязанный к `product_id` поставщика (`supplierKey=somadeth`, автопродажа).

## 3. Как работает выдача

- Клиент покупает → оплачивает (Payme/Click/Stars) → бот вызывает `purchase`.
- Ответ разбирается автоматически (ищет поля delivery/content/credentials/code/
  key/data/items); что пришло — то и выдаётся клиенту.
- **Если у кошелька не хватило баланса (400) или ошибка** — заказ уходит в
  ручную выдачу с кодом проверки, деньги/рефералы клиента НЕ теряются. Пополни
  кошелёк поставщика и довыдай через `/give` или «Проверка кодов».

## 4. Важно

- Перед боевыми продажами **пополни кошелёк поставщика** (иначе каждый заказ
  падает в ручную выдачу).
- Тестовый ключ, что был прислан в чат, недействителен — рабочий стоит в Railway.
- Если формат ответа `purchase` окажется нестандартным и клиент увидит «сырой»
  JSON — пришли один пример ответа, поправлю разбор поля выдачи.
