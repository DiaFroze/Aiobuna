### Что произойдёт после заполнения

С этими данными я:
1. пропишу авторизацию и endpoints в `http-adapter.ts`;
2. замаплю ответы в наши типы `SupplierProductDTO` / `PlaceOrderResult`;
3. включу `SUPPLIER_MODE=live`, добавлю поставщика в `/admin/suppliers` (ключ шифруется);
4. если выдача асинхронная — реализую webhook-обработчик или опрос статуса в воркере.
