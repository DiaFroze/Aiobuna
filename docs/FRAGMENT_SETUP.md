# Подключение Fragment — пошагово

Автоматическая выдача Telegram Stars и Premium.
Сейчас выдача ручная и **это нормально работает** — можно продавать. Этот файл о том,
как сделать её автоматической.

---

## Правило номер один

**Seed-фраза (12 или 24 слова) — это и есть твои деньги.**

Кто её увидел — забрал кошелёк целиком. Не через суд, не через поддержку — просто забрал,
за секунды, и вернуть невозможно.

Поэтому:

- ❌ Не отправляй её в чат — ни мне, ни кому-либо
- ❌ Не пиши в файл внутри проекта
- ❌ Не сохраняй в заметки телефона, скриншоты, Telegram «Избранное»
- ✅ Только в Railway → Variables, вводишь сама, своими руками

Если seed-фраза где-то засветилась — сразу создай новый кошелёк и переведи всё туда.
Старый считай потерянным.

---

## Шаг 1. Заведи отдельный «рабочий» кошелёк

Не используй кошелёк, где лежат твои сбережения.

1. Создай **новый** TON-кошелёк (Tonkeeper) — он будет только для бота
2. Seed-фразу от него запиши на бумаге и убери
3. Держи там сумму на 1–2 дня торговли, не больше

Зачем: seed-фраза этого кошелька будет лежать на сервере. Если сервер взломают,
потеряешь только рабочую сумму, а не всё.

Пополняешь его сама раз в пару дней с основного кошелька. Основной на сервер не попадает
никогда.

---

## Шаг 2. Реши, как подключаться

| | Свой кошелёк | Через сервис-посредник |
|---|---|---|
| Что хранится на сервере | seed-фраза | только API-ключ |
| Комиссия | нет | есть |
| Если сервер взломают | уйдут деньги с рабочего кошелька | уйдёт только доступ к API |
| Если сервис закроется | ничего не случится | зависишь от него |

**Рекомендую свой кошелёк** — при условии шага 1. Рабочая сумма маленькая, комиссий нет,
ни от кого не зависишь.

Если выберешь сервис — напиши мне название, я изучу его документацию и подключу.

---

## Шаг 3. Что понадобится

Подготовь заранее, но **никуда не записывай в проект**:

- [ ] Seed-фраза рабочего кошелька (12 или 24 слова)
- [ ] Адрес этого кошелька (начинается на `UQ` или `EQ`)
- [ ] Пополнен на рабочую сумму в TON или USDT-TON
- [ ] Аккаунт на fragment.com, вход через Telegram
- [ ] Кошелёк подключён к Fragment

Про KYC: без него Fragment ограничивает суммы. Нужен ли он тебе — зависит от оборота.
Начни без KYC, посмотри на лимиты.

---

## Шаг 4. Куда вписывать значения

**Railway → твой проект → вкладка Variables → New Variable**

Вписываешь ты сама. Я эти значения не вижу и не должна видеть.

| Имя переменной | Что вписать |
|---|---|
| `FRAGMENT_MODE` | `live` — включить автовыдачу. `off` — оставить ручную |
| `FRAGMENT_SEED` | seed-фраза рабочего кошелька, слова через пробел |
| `FRAGMENT_WALLET` | адрес кошелька (`UQ…`) |
| `FRAGMENT_COOKIES` | нужно только для режима KYC, иначе пропусти |

После добавления Railway перезапустит бота сам.

⚠️ Пока `FRAGMENT_MODE` не равно `live` — ничего не изменится, выдача останется ручной.
Это специально: сначала вписываешь данные, потом включаешь.

---

## Шаг 5. Проверка перед боем

Не переводи в автомат сразу — сначала убедись, что работает.

1. Заведи товар «10 Stars» по минимальной цене, спрятанный от клиентов
2. Купи его сама со второго аккаунта
3. Посмотри, дошли ли звёзды
4. Только после этого включай настоящие товары

---

## Чего ожидать честно

**Официального API у Fragment нет.** Всё работает через разбор их сайта. Это значит:

- Fragment может поменять сайт — выдача сломается без предупреждения
- Сломается она в худший момент: клиент заплатил, товар не пришёл

Поэтому ручная выдача остаётся запасным вариантом навсегда. Если автомат отвалится,
переключаешь `FRAGMENT_MODE` в `off` и продолжаешь работать руками, пока чиню.

Заведи привычку: раз в день проверять, что заказы уходят.
